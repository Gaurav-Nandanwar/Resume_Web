# Interactive Animated Resume Website

A stunning, interactive, and fully animated resume website built with React and Framer Motion. Features smooth scrolling animations, interactive elements, and a modern design.

## ✨ Features

- **Animated Hero Section** - Dynamic typewriter effect with smooth animations
- **Interactive Navigation** - Sticky navbar with active section highlighting
- **Skills Showcase** - Animated progress bars with category filtering
- **Experience Timeline** - Beautiful timeline with hover effects
- **Projects Gallery** - Featured projects with overlay effects
- **Education & Certifications** - Professional presentation of credentials
- **Contact Form** - Interactive form with validation
- **Smooth Scroll Animations** - Framer Motion powered animations
- **Responsive Design** - Mobile-first, works on all devices
- **Modern UI/UX** - Gradient accents, glassmorphism effects

## 🚀 Technologies Used

- **React 19** - Modern UI library
- **Vite** - Fast build tool
- **Framer Motion** - Animation library
- **React Simple Typewriter** - Typewriter effect
- **CSS3** - Custom styling with gradients

## 📦 Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd Resume
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 🏗️ Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.
